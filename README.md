# Автобус-кузнечик

Учебный проект по разработке через тестирование (TDD).
Автор ТЗ и тестов — Агапов Арсений Михайлович, БСБО-16-23.

Автобус перевозит до восьми пассажиров, движется на колёсах и прыгает
с помощью пружинных ног. Дальность прыжка зависит от загрузки.

## Материалы

- [SPEC.md](SPEC.md) — техническое задание, версия 0.3.
- [TEST_CASES.md](TEST_CASES.md) — 20 модульных и 4 сценарных тест-кейса.
- `tests/` — тесты на unittest и обёртка-пилот для сценариев.
- [REVIEW_Bocharov.md](REVIEW_Bocharov.md) — замечания ревьюера C,
  ответы автора и подтверждение исправлений.

## Проверка

Требуется Python 3.12. Сторонние зависимости не нужны.
Команды выполняются из корня репозитория:

```bash
python -m compileall -q tests
python -m unittest discover -s tests -v
```

В Windows можно использовать `py -3.12` вместо `python`.
