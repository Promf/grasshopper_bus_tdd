## 1. Назначение

Автобус-кузнечик перевозит до восьми пассажиров по земле. На обычных участках он едет на колёсах, а через короткие препятствия перепрыгивает с помощью пружинных ног. Чем больше пассажиров, тем меньше допустимая дальность прыжка. Программа моделирует команды и изменение состояния, а не физику полёта.

## 2. Стихия и конструкционный элемент

Обязательный конструкционный элемент — четыре несущих колеса для наземной езды. Количество колёс фиксировано, повреждения и замена не моделируются. Дополнительный элемент — две выдвижные пружинные ноги. Заряженные пружины означают подготовленные к прыжку ноги и блокируют обычную езду; после прыжка или сброса ноги убраны. Признак `springs_charged` описывает их рабочее состояние.

Транспорт не плавает и не совершает длительный полёт. Прыжок атомарен: команда завершается приземлением, а не переходом в состояние «в воздухе». Каждая успешная поездка и каждый прыжок заканчиваются остановкой. Поэтому обслуживание доступно между командами, отдельный метод stop и флаг движения не нужны. Стоянка означает остановленное состояние, а не специальную точку карты; зарядное устройство считается доступным на любой остановке.

## 3. Публичный интерфейс

Модуль `grasshopper_bus.py`. Класс `GrasshopperBus`. Python 3.12, стандартная библиотека. Команда проверки из корня репозитория: `python -m unittest discover -s tests -v` (Windows: `py -3.12 -m unittest discover -s tests -v`). До появления grasshopper_bus.py ожидается ошибка импорта; это не успешное выполнение 24 тестов. Ввод через консоль, GUI, сеть и сторонние зависимости для класса не требуются.

### 3.1. Общие правила

Все расстояния, количество пассажиров и ресурсы задаются целыми числами Python `int`, кроме `bool`. Значения `1.0`, строки, None, NaN и бесконечность недопустимы. Ошибка проверяемого типа — `ValueError`, как и ошибка диапазона. Неверное количество аргументов вызова обрабатывается обычным механизмом Python (`TypeError`) и не относится к предметной валидации.

При любом отказе сохраняются значения и точные типы всех публичных атрибутов из §3.3. Например, замена int 100 на float 100.0 недопустима, хотя эти значения равны при сравнении. Поведение детерминировано. Экземпляры независимы. Неуказанные в описании команды атрибуты сохраняются. Денежные затраты, случайные события и время обслуживания отсутствуют.

### 3.2. Конструктор

```python
def __init__(self, name: str, energy: int = 100) -> None:
```

`name` — строка, содержащая хотя бы один непробельный символ; хранится исходная строка без обрезки. `energy` — целое от 0 до 100 включительно. При нарушении этих правил — `ValueError`. Сначала проверяется имя, затем энергия.

Начальные значения: имя из аргумента, энергия из аргумента, passengers=0, doors_open=False, springs_charged=False, position_m=0, mileage_m=0, max_jump_m=8.

### 3.3. Публичные атрибуты

| Атрибут | Тип | Единицы и допустимые значения | Доступ |
| --- | --- | --- | --- |
| name | str | Непустое непробельное имя | чтение |
| energy | int | Условные единицы, 0…100 | чтение |
| passengers | int | Человек, 0…8 | чтение |
| doors_open | bool | Двери открыты | чтение |
| springs_charged | bool | Пружины заряжены, ноги подготовлены | чтение |
| position_m | int | Знаковая позиция на одной оси, м | чтение |
| mileage_m | int | Общий путь на колёсах и прыжками, м, ≥0 | чтение |
| max_jump_m | int | Текущий предел прыжка, м, 4…8 | чтение |

Присваивание любому перечисленному атрибуту вызывает `AttributeError`, даже если значение не меняется. Внутреннее устройство класса не регламентируется.

Предел прыжка: `max_jump_m = 8 - passengers // 2`. Для 0…8 пассажиров значения соответственно 8, 8, 7, 7, 6, 6, 5, 5, 4. Значение актуально сразу после посадки или высадки, в том числе при заряженных пружинах.

### 3.4. Методы

#### 3.4.1. Открыть двери

```python
def open_doors(self) -> None:
```

Устанавливает doors_open=True. Повтор разрешён. Заряженные пружины не мешают открытию. Энергия и заряд пружин сохраняются. Доменных исключений нет.

#### 3.4.2. Закрыть двери

```python
def close_doors(self) -> None:
```

Устанавливает doors_open=False. Повтор разрешён. Остальное состояние сохраняется. Доменных исключений нет.

#### 3.4.3. Посадить пассажиров

```python
def board(self, count: int) -> None:
```

count — целое 1…8. Порядок проверок: аргумент (`ValueError`), двери должны быть открыты (`DoorsClosedError`), passengers+count ≤8 (`CapacityError`). При успехе passengers увеличивается на count, max_jump_m пересчитывается. Заряд пружин и энергия не меняются. Посадка после зарядки пружин разрешена.

#### 3.4.4. Высадить пассажиров

```python
def alight(self, count: int) -> None:
```

count — целое 1…8. Порядок проверок: аргумент (`ValueError`), открытые двери (`DoorsClosedError`), passengers ≥ count (`CapacityError`). При успехе passengers уменьшается на count, max_jump_m пересчитывается. Энергия и заряд пружин сохраняются.

#### 3.4.5. Проехать на колёсах

```python
def move(self, distance_m: int) -> int:
```

distance_m — целое от -100 до 100, кроме нуля. Знак задаёт направление. Порядок проверок: аргумент (`ValueError`), двери закрыты (`DoorsOpenError`), пружины не заряжены (`SpringsStateError`), достаточная энергия (`NoEnergyError`). Расход равен округлённому вверх `abs(distance_m)/5`. Например, 1 и 5 м стоят 1 единицу, 6 м — 2, 100 м — 20. Число пассажиров на расход езды не влияет.

Успех: position_m += distance_m, mileage_m += abs(distance_m), energy уменьшается на расход. Возврат — abs(distance_m). Точный остаток энергии 0 допустим. После команды автобус остановлен. Поверхность одна, карта отсутствует, границы координаты не заданы.

#### 3.4.6. Зарядить пружины

```python
def charge_springs(self) -> None:
```

Проверки: закрытые двери (`DoorsOpenError`), пружины ещё не заряжены (`SpringsStateError`), energy ≥10 (`NoEnergyError`). Успех: energy -=10; springs_charged=True. Повторная зарядка запрещена, даже при нехватке энергии. Заряд сохраняется до успешного прыжка либо явного сброса.

#### 3.4.7. Сбросить заряд пружин

```python
def release_springs(self) -> None:
```

Устанавливает springs_charged=False, не возвращая потраченную энергию. Допускается с открытыми дверями и при уже разряженных пружинах. Исключений предметной области нет. Используется для отмены прыжка и возврата к обычной езде.

#### 3.4.8. Прыгнуть

```python
def jump(self, distance_m: int) -> int:
```

distance_m — целое -8…8, кроме нуля. Порядок проверок:

1. Тип и абсолютный диапазон аргумента — `ValueError`.
2. Двери закрыты — иначе `DoorsOpenError`.
3. Пружины заряжены — иначе `SpringsStateError`.
4. abs(distance_m) ≤ max_jump_m — иначе `JumpTooFarError`.

Успех: position_m += distance_m, mileage_m += abs(distance_m), springs_charged=False. Возврат — abs(distance_m). Дополнительного расхода энергии нет: он оплачен при зарядке пружин. Прыжок при energy=0 разрешён при выполнении остальных условий. Неуспешный прыжок не разряжает пружины. Проверяется текущая, а не прежняя загрузка автобуса.

Прыжок абстрактно представляет преодоление ямы; отдельные препятствия, их ширина, координаты и столкновения не моделируются. Разработчик не должен добавлять скрытых ограничений маршрута.

#### 3.4.9. Пополнить энергию

```python
def recharge(self, amount: int) -> None:
```

amount — целое 1…100. Некорректный аргумент вызывает `ValueError`. При успехе energy = min(100, energy+amount). Это добавляемая величина, не целевой уровень. Открытые двери, пассажиры и заряженные пружины не мешают зарядке. Остальные поля не меняются.

#### 3.4.10. Получить состояние

```python
def get_status(self) -> dict:
```

Возвращает новый словарь с ровно восемью ключами из таблицы §3.3 и их текущими значениями. Изменение словаря не меняет объект. Метод не изменяет состояние. Исключений предметной области нет.

## 4. Сценарии и тестовый план

### 4.1. Модульные примеры AAA

1. Arrange: новый автобус. Act: move(6). Assert: возврат 6, position=6, mileage=6, energy=98.
2. Arrange: energy=1. Act: move(6). Assert: NoEnergyError и полный снимок без изменений.
3. Arrange: открытые двери, 8 пассажиров. Act: board(1). Assert: CapacityError и неизменное состояние.
4. Arrange: 8 пассажиров, закрытые двери, заряженные пружины. Act: jump(5). Assert: JumpTooFarError, заряд сохранён.

Полный перечень TC-001…TC-020 находится в TEST_CASES.md. Реализация проверяется через публичный интерфейс, без чтения приватных полей.

### 4.2. Сложные сценарии GWT

#### 4.2.1. Рейс через яму — TC-021

Given: новый автобус, энергия 100, пассажиров 0.  
When: пилот сажает 4 пассажиров и закрывает двери, едет 10 м, заряжает пружины.  
Then: энергия 88, предел прыжка 6 м.  
When: прыгает на 6 м, едет назад 5 м и высаживает всех, закрывая двери.  
Then: position=11, mileage=21, energy=87, passengers=0; пружины разряжены, двери закрыты.

#### 4.2.2. Слишком тяжёлый автобус — TC-022

Given: полный заряд, 8 пассажиров, двери закрыты, пружины заряжены.  
When: попытка прыгнуть на 6 м.  
Then: JumpTooFarError; энергия 90 и заряд пружин сохраняются.  
When: пилот высаживает 4 пассажиров, закрывает двери и повторяет прыжок на 6 м.  
Then: position=6, mileage=6, energy=90, passengers=4; пружины разряжены.

#### 4.2.3. Последний заряд — TC-023

Given: энергия 12, пустой автобус с закрытыми дверями.  
When: проехать 6 м и зарядить пружины.  
Then: энергия 0, пружины заряжены.  
When: прыгнуть на 8 м, затем попытаться проехать 1 м.  
Then: прыжок успешен, езда даёт NoEnergyError без изменений.  
When: пополнить энергию на 5 и проехать назад 5 м.  
Then: position=9, mileage=19, energy=4, пассажиров 0.

#### 4.2.4. Отмена прыжка — TC-024

Given: новый автобус с открытыми дверями.  
When: попытаться проехать 5 м.  
Then: DoorsOpenError без изменений.  
When: посадить 2 пассажиров, закрыть двери, зарядить пружины и попытаться ехать.  
Then: SpringsStateError; энергия 90, заряд пружин сохранён.  
When: отменить прыжок сбросом пружин, проехать 5 м вперёд и 5 м назад.  
Then: position=0, mileage=10, energy=88, passengers=2; пружины разряжены.

## 5. Граничные случаи

- Вместимость: 8 пассажиров допустимы, девятый вызывает CapacityError.
- Дальность: пустой автобус прыгает ровно 8 м; полный — ровно 4. Дистанция 5 у полного даёт JumpTooFarError, 9 у любого — ValueError.
- Энергия: 10 хватает ровно на зарядку пружин, а затем прыжок возможен при нуле. Зарядка при 9 — NoEnergyError.
- Езда на 6 м стоит 2, а не 1. Знак не меняет расход и пробег.
- Пополнение не превышает 100; bool никогда не принимается вместо числа.

## 6. Исключения и порядок ошибок

Все классы исключений экспортируются из grasshopper_bus.py. BusError непосредственно наследует Exception. Следующие доменные исключения наследуют BusError; текст сообщения не является частью проверяемого контракта.

| Исключение | Условие |
| --- | --- |
| ValueError | Некорректный тип или значение проверяемого аргумента |
| AttributeError | Присваивание публичному атрибуту только для чтения |
| DoorsOpenError | Открытые двери при езде, прыжке или зарядке пружин |
| DoorsClosedError | Закрытые двери при посадке или высадке |
| CapacityError | Переполнение автобуса или высадка большего числа пассажиров, чем находится внутри |
| NoEnergyError | Недостаток энергии для езды или зарядки пружин |
| SpringsStateError | Езда с заряженными пружинами, повторная зарядка или прыжок без заряда |
| JumpTooFarError | Дистанция в абсолютном диапазоне ±8, но больше текущего предела по загрузке |

Приоритеты определены отдельно в §3.4. У всех методов с аргументами сначала проверяется аргумент, даже если операция запрещена текущим состоянием. Ошибки атомарны, включая изменение энергии, пассажиров, координат и пружин.
