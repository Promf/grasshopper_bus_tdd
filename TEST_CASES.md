# Test Case Specification Автобус кузнечик

Версия 0.3. 20 модульных и 4 сценарных TC (83,3% / 16,7%). Все ожидаемые ошибки сохраняют полный снимок состояния, включая точные типы полей. Оба помощника reject копируют снимок до вызова; checked_status проверяет набор ключей, точные типы и соответствие публичным атрибутам до/после отказа, а также в tearDown каждого теста. Каждый TC соответствует одному тест-методу, внутри возможны подслучаи. Имена тестов содержат ID и повторяют его в docstring.
